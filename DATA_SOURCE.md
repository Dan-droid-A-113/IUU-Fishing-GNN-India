# Data sources

Record every dataset here **before** using it: source, access date, licence, geographic extent, temporal extent, columns and restrictions.

## 1. Synthetic AIS (Mode A) — in use

| Field | Value |
|---|---|
| Source | Generated by `src/synthetic.py` (seeded, reproducible) |
| Access date | generated at runtime |
| Licence | project code; synthetic output carries no third-party rights |
| Extent | IN-GOM bbox: 8.0–10.2°N, 77.9–80.2°E |
| Time | 2024-02-01 to 2024-02-08 UTC (configurable) |
| Columns (raw) | mmsi (`SYNTH…`), timestamp, lat, lon, sog, cog, heading, nav_status, ship_type, length, width, draught, source |
| Hidden truth | true positions of every scheduled report, transmit/receive flags, miss reason, behaviour, planted events, injected errors |
| Restrictions | Labels are `synthetic_demo_*`. **Never present them as real observations or as evidence of illegal fishing.** Hidden truth is for evaluation only and must not be used as model input. |

### 1b. Synthetic AIS for Milestone 2+ (`data/synthetic_m2/`)

- **Size:** 60 days (2024-02-01 to 2024-04-01 UTC), 62 vessels (40 fishing, 12 of them suspicious "actors"), 6 reefer carriers (4 suspicious, each with its own network of 3 actors), 12 cargo or tanker ships, 2 tugs and 2 ferries.
- **Receiver outage:** a receiver-cluster outage repeats every 233 h.
- **Other settings:** generated by `m2_synthetic_config()` with seed 42. The same restrictions as above apply.

## 2. Spatial layers — in use (approximate placeholders)

| Layer | Source used now | CRS | Uncertainty | Replace with |
|---|---|---|---|---|
| Land mask / coastline | `global-land-mask` package (GLOBE 30″ DEM, NOAA) | EPSG:4326 | ~1 km; small islets may be missed | GSHHG or OSM coastline if finer detail is needed |
| Gulf of Mannar Marine National Park | hand-digitised outline of the island/reef band | EPSG:4326 | several km | WDPA / Protected Planet polygon (check licence) |
| India–Sri Lanka maritime boundary (used as `eez_distance_m`) | turning points recalled from the 1974/1976 agreements | EPSG:4326 | several km; the northern end is an extension | Marine Regions EEZ boundaries (CC-BY) |
| Ports / harbours / anchorage | approximate public locations, snapped seaward | EPSG:4326 | 1–3 km | World Port Index (public domain) |
| Fishing grounds | invented for the demo | EPSG:4326 | not real | official or effort-derived zones |
| AIS receivers (coverage model) | invented for the demo | — | not real stations | not needed for real data |

Other known layers not yet included: the Gulf of Mannar Biosphere Reserve (larger extent), the Palk Bay Dugong Conservation Reserve, and bathymetry (GEBCO).

## 3. REAL data: Global Fishing Watch (Mode B + C), in use from notebook 02

| Field | Value |
|---|---|
| Source | Global Fishing Watch API v3, via the official `gfw-api-python-client` |
| Datasets | `public-global-fishing-events`, `-encounters-events`, `-loitering-events`, `-port-visits-events`, `-gaps-events` (AIS off), `public-global-sar-presence` (Sentinel-1, filtered to detections not matched to AIS), `public-global-fishing-effort` |
| Access date | written automatically to `data/processed/real_gfw/provenance.json` on each run |
| Licence | GFW API terms: **non-commercial use, attribution to Global Fishing Watch required** |
| Extent | Southern Indian EEZ bbox 5.0–16.0°N, 70.0–82.0°E (`IN-SOUTH`; includes Kerala, Lakshadweep Sea, Tamil Nadu, Gulf of Mannar – Palk Bay, and parts of the Sri Lanka / Maldives EEZs) |
| Time | 2021-01-01 to 2025-12-31 (5 years; earlier runs used 2024-01-01 to 2025-12-31) |
| Downloaded volume (5-year run) | 1,878,474 events in total; Sentinel-1: 136,950 cell-days with detections that match no AIS vessel and 181,002 cell-days with any detection (imaging footprint). The earlier 2-year run (2024–2025) had 1,048,080 events. |
| Storage | `MyDrive/india-fishing-gnn-data/real_gfw` (processed) and `.../gfw_raw_cache` (per-month download cache) |
| Cleaning (notebook 04b) | gaps shorter than 1 h or longer than 30 days are not counted as gaps (5-year run: 913 of 1,004 kept; raw maximum 30,439 h); single-event durations capped at 7 days; only fishing-related vessels and their encounter partners are modelled |
| Restrictions and limits | No raw AIS tracks (events and gridded products only). Small Indian vessels often carry no AIS. No confirmed illegal-fishing labels exist. The token is kept in Colab Secrets and never saved. Vessel IDs, names and MMSIs are anonymised in outputs, and the mapping is private (git-ignored). |

## 3b. Other open AIS: not used

- Global Fishing Watch requires registration, acceptance of its terms, an API token (`GFW_API_TOKEN`) and attribution. Adapter interface: `src/data_io.GFWAdapter`.
- Any other licensed AIS CSV can be loaded with `load_local_ais_csv`. Add a row to this file first.

## 4. SAR verification (Mode C) — in use (held-out evidence only)

- Global Fishing Watch Sentinel-1 vessel detections that match no AIS vessel (`public-global-sar-presence`, gridded daily).
- Used only to **validate** the real-data model (unmatched detections within 20 km of a gap). They are never used as a model input or training target.
- For synthetic data, `sar_detection_flag` stays `<NA>` (unknown), never `False`.
